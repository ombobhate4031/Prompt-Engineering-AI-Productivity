04. Prompt Testing and Evaluation Report

1. Introduction

Prompt testing is the process of checking how effectively an AI tool responds to different prompts.

It helps improve the quality, accuracy and usefulness of AI-generated responses.

2. Objectives

- Test different prompting techniques.
- Compare expected and actual outputs.
- Identify unclear prompts.
- Improve prompt quality.
- Evaluate AI-generated responses.

3. Prompt Testing Examples

Test 1: Zero-shot Prompting

Prompt:

"Explain Artificial Intelligence in simple English."

Expected Output:

A simple explanation of Artificial Intelligence.

Actual Output:

AI explained as a technology that enables machines to perform tasks that normally require human intelligence.

Result: Pass.

Test 2: Few-shot Prompting

Prompt:

"Classify this sentence as Positive or Negative: I really enjoyed this workshop."

Expected Output:

Positive.

Actual Output:

Positive.

Result: Pass.

Test 3: JSON Generation

Prompt:

"Generate student details in JSON format."

Expected Output:

Valid JSON containing student information.

Actual Output:

AI generated structured student information using JSON.

Result: Pass.

Test 4: Python Code Generation

Prompt:

"Write a Python program to check whether a number is even or odd."

Expected Output:

A working Python program that identifies even and odd numbers.

Actual Output:

AI generated a Python program using the modulo operator.

Result: Pass after code verification.

Test 5: Text Summarization

Prompt:

"Summarize Artificial Intelligence in five bullet points."

Expected Output:

Five short and meaningful points.

Actual Output:

AI generated five important points about Artificial Intelligence.

Result: Pass.

4. Prompt Evaluation Criteria

Criteria| Description
Accuracy| Correctness of the response
Relevance| Response matches the prompt
Clarity| Easy to understand
Completeness| Includes required information
Format| Follows the requested output format

5. Prompt Improvement Example

Original Prompt:

"Explain Python."

Improved Prompt:

"Act as a Python programming teacher. Explain Python programming in simple English using five bullet points and provide one practical example."

Improvement:

The improved prompt provides a clear role, context, instructions and output format.

7. Conclusion

Prompt testing helps users understand how to create effective prompts and improve AI responses. By testing different prompts and evaluating their outputs, we can achieve better accuracy, clarity and productivity.
